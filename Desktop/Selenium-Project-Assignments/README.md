# Selenium Assignments and Capstone Project

## Overview

This repository contains Selenium WebDriver assignments, certificates and a Capstone project completed using Python, Selenium WebDriver, and Pytest.

The work is organized into three separate folders:

- `Assignments/` – Contains the respective Selenium assignments completed during the course.
- `Project/` – Contains the Capstone project 1, implementing an end-to-end e-commerce purchase automation workflow.
- `Course_Certificates/` – Contain the three Coursera certificates which were completed during this Selenium training.
